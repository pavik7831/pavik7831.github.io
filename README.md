# Pavithran Kumaravel — Developer Portfolio

A responsive, clean-white portfolio built with plain HTML, CSS and JavaScript. The content is based on the supplied resume, including professional summary, skills, work experience, education, contact details and a downloadable resume PDF.

## Files
- `index.html` — portfolio content
- `styles.css` — responsive styling
- `script.js` — mobile navigation and dynamic copyright year
- `assets/favicon.svg` — site icon
- `assets/resume.pdf` — resume PDF linked from the homepage
- `.nojekyll` — GitHub Pages support file

## Run locally
1. Extract the ZIP.
2. Open the folder in VS Code.
3. Open `index.html` in your browser. No Node.js, Python, npm install or database is required.

## Before publishing
- Review the resume PDF and confirm you want its contact details publicly available.
- The GitHub and LinkedIn links are filled from the resume; confirm both are correct and accessible.
- The four featured projects include Airport Fuel Management and Employee Management System as portfolio projects, plus the Timesheet and Jewellery Reporting work described in the resume. Make sure the project status and descriptions reflect what you are comfortable presenting in an interview.
- Add verified repository or demo links only when they are ready to share.

## Free deployment with GitHub Pages
1. Sign in at https://github.com/ or create a free account.
2. Create a **public** repository named `YOUR-USERNAME.github.io` (replace with your GitHub username).
3. Upload the contents of the extracted folder to the repository root. `index.html` must be at the root.
4. Commit the files to the `main` branch.
5. Open **Settings → Pages**.
6. Under **Build and deployment**, select **Deploy from a branch**, choose `main` and `/(root)`, then save.
7. After deployment, visit `https://YOUR-USERNAME.github.io`. Initial publishing can take several minutes.

## Important
This is a static website. The contact email opens the visitor's email app; there is no backend or database. The site uses no paid assets or paid hosting. The included resume PDF will be publicly downloadable once the site is published.
